### Troubleshooting:
- If pages don't load, try refreshing
- Clear your browser cache (Ctrl+Shift+Delete)
- Make sure GitHub Pages is enabled in repository settings

Go to: https://github.com/CoolhandElec/test-app/settings/pages

Select:
- Source: Deploy from a branch
- Branch: main
- Folder: / (root)

Then click Save.
